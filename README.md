# Сповіщення про матчі в Telegram

Бот пише в Telegram-канал про кожен матч Ліги чемпіонів і кожну гру Барселони
(Ла Ліга, кубки, товариські):

- за 10 годин до початку;
- за 30 хвилин до початку;
- результат після завершення.

Дані беруться з відкритого API ESPN, запускається бот кожні 5 хвилин у GitHub Actions.
Власний сервер не потрібен.

## Налаштування

1. **Бот.** У Telegram напишіть `@BotFather`, команда `/newbot`. Збережіть токен.
2. **Канал.** Створіть канал і додайте бота адміністратором із правом публікувати повідомлення.
3. **ID каналу.** Для публічного каналу це `@назва_каналу`. Для приватного — число виду
   `-1001234567890`: перешліть будь-який пост каналу боту `@userinfobot`.
4. **Репозиторій.** Створіть на GitHub **публічний** репозиторій і завантажте в нього цю теку.
   У приватному не вистачить безкоштовних хвилин Actions.
5. **Секрети.** У репозиторії: Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN` — токен від BotFather;
   - `TELEGRAM_CHAT_ID` — ID каналу.
6. **Перевірка.** Вкладка Actions → «Сповіщення про матчі» → Run workflow.

## Що варто знати

- GitHub запускає розклад із запізненням на 5–15 хвилин, тому «за 30 хвилин» може прийти
  за 15–25. У тексті завжди стоїть точний час початку.
- Якщо бот не працював довше 6 годин після початку матчу, результат цього матчу не надсилається.
- `state.json` — пам'ять бота про вже надіслані сповіщення. Бот оновлює його сам.
- GitHub вимикає розклад, якщо в репозиторії 60 днів немає комітів. Улітку, коли матчів немає,
  зайдіть в Actions і натисніть Enable workflow, якщо він вимкнувся.
- Назви команд англійською, як у ESPN. Тексти повідомлень — у `matchbot/messages.py`.

## Локальний запуск

```bash
pip install -r requirements-dev.txt
DRY_RUN=1 python -m matchbot   # показати, що було б надіслано, нічого не відправляючи
python -m pytest --cov=matchbot
```
